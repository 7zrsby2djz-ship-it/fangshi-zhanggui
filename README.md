# 坊市掌櫃

災後台灣山區聚落的小店推理＋探索遊戲。舞台是約 2029 年那場說不清楚的災變之後一百年：中部山區被整片抬升，海在西邊斷成一道往下流的缺口，霧、霜、會自己亮的燈、停在 2029 年 12 月的舊物到處都是。聚落裡的人把身體慢慢適應這個異常環境的過程叫「修行」——吐納、築基、金丹、元嬰都是在地的俗稱，不是一部仙俠史；靈石是當地流通的礦物貨幣兼「適應」材料。主角許衡（許家店老闆）跟長生當鋪押了壽命、只剩十八個月，靠看穿來客的真假、讀懂消息做生意，也可以往聚落外面走，撿遺物、看異象，讓身體多適應一點。

語氣：現代台灣華語（店、管理處、派出所、寒潭會），不是古風。北邊的霜、一百年前的災變到底是什麼，遊戲**不給官方答案**——封印、礦脈、還在運轉的舊機器、當鋪的帳、什麼都沒有，都只是人物的說法。狐尾燈是**唯一一盞**的特殊物品，只會讓你比較注意得到別人的小動作，不會測謊。

目前進度：**從開張到結局完整可玩**，一輪約一到兩小時。另有消息簿、管理處告發、墨線物品圖示、NPC 墨線表情。

時間怎麼走：**不是每月一回合**。時間是連續的——有事的日子一天一天過（四月六天、五月六天、六月「結霜」四天），中間平淡的二十來天直接跳過，第二天早上用一張「過了些日子」的卡交代，接著是依你之前做的事出現的卡片。中途沒有結算畫面、沒有評等；規費只在結霜前收一次（五月那段的最後一天）。每天早上還可能遇到一件沒有固定日子的「散事」（`events.yaml` 的 `drift`），有的是奇遇，有的是北邊那件事的伏筆。評等只在最後算一次，整段日子一起算。

終章：北礦六月結霜，聚落在慌，沒有人說得清那是什麼。第一天有來要熱水的老人（奇遇），第二天市集、第三天長生當鋪破例開門，第四天**元嬰級的寒漪與玄霜巡守隊前隊長雪衣老人來店裡拜訪**。寒漪不是憑空出現的：葉理事提前送拜訪信（寫明她三天前從總會出發），消息怎麼傳上山有四條路——陸調查員送上山的卷宗（告過北林／張主任的案子）、盲婆婆託挑夫帶給雪衣老人的信、管理處外出登記簿（你去過北礦圍籬、聽過通風口、看過霜的源頭或播過錄音帶）、或礦上信差照例附上的十二年前舊卷宗——結霜第一天早上會出一張「消息走到了山上」交代是哪一條。拜訪時你拿得出什麼，取決於前兩個月的選擇，決定三種結局（拜訪與結局段落會依你在外面看過的東西多出補述）：

- **守燈**：手上有狐尾燈，且認了玄霜隊的淵源（盲婆婆相認／跟她去看燈／鐵師傅的玄霜刀／燈照老人）。
- **清帳**：查到十二年前的帳（當面跟錢不語對帳、白姐的舊事、帳冊缺頁、張主任或北林的案子交給陸調查員）。
- **典當**：什麼都不拿出來、把燈或招牌當給長生當鋪、或第四天不在店裡（空櫃變體）。

> ⚠️ 劇透警告：`content/deals.yaml` 裡寫著每筆交易的真相，`content/intel.yaml` 寫著每則消息的真假與後果。只想玩的人請不要先看。

## 怎麼玩

用瀏覽器打開 `dist/game.html`（單一檔案，手機直式為主；線上版：https://7zrsby2djz-ship-it.github.io/fangshi-zhanggui/ ）。

### 甩手掌櫃：店自己會做生意

舊版是一個客人一個客人地殺價；現在**店自己開著**，你只管定方針、請人、修店面，然後出門。

- **早上**：看卡片（店裡發生的事、散事、奇遇），有選項的先選，再按「開門」。
- **白天**：上午、下午、傍晚三個時段，每段可以出門一趟——聚落裡（舊國小、聽雨茶館、管理處、後山住宅區、長生當鋪）或往外走探索。不想出門就「直接打烊」（要按兩次）。
- **找上門的事**：故事人物、可疑的貨，會以「找上門的事」出現在店面上。**不花時段**：夥計已經先替你問過來歷、追問、查證（看你請了誰），你讀完逐字稿，做一個決定；也可以花一點眼力自己看一眼，或「先放著」。標著「故事」「今天過後就沒了」。
- **晚上**：店自動結帳，給你一張**日報**（來客、營業額、收了幾批貨、假貨、夥計撿到的舊物、客人閒聊、規費、靜坐、負擔），再加一行「明天」的提醒。

「店務」頁可以調：

| 項目 | 內容 |
| --- | --- |
| 方針（5 組） | 收購（嚴／普通／寬）、定價（便宜／公道／貴）、招牌（低調／張揚）、晚上修行（不投／一半／全力）、收哪些貨（藥材／礦材／舊物／日用／**來路不明**） |
| 夥計（10 位可請＋2 位只能從成就帶進來） | 阿岳、小葉、蔡姐、老符、阿凱、阿妹、阿花嬸、黑狗、溫伯、舒琪；阿宏、旺伯。每人有特質（會賣、眼力、對帳、手腳不乾淨、嘴不牢、守夜……）和自己的小故事 |
| 店面（10 處） | 招牌、奉茶桌、鐵捲門、冷藏櫃、加釘貨架（多一個夥計名額）、鑑定燈、靜室、後院、推車、打通隔壁；修得越多，店的稱號從「巷口小店」升到「山城第一家」 |
| 探索裝備（8 件） | 登山杖、頭燈、繩索、防寒外套、採集袋、氧氣瓶、安全吊帶、平安符：多走一處、擋特定死法、降低回程風險、提高負擔上限 |

### 負擔與死亡

往下走，身體會累積**負擔**（地點越深越重，標「會累」的地方再＋1）。上限＝5＋2×（吐納層數−4）＋裝備。超過上限，往上爬回聚落時可能上不來（第一次會「差一點」，之後就是真的）。每晚會退掉一些負擔（靜室更多）。

遊戲裡有 **46 種死法**（探索 23、回程負擔 8、遺物 8、店裡 7），每一種都有預兆：地點上的紅字警告、粉筆字、別人的勸告、遺物前幾天的怪事。必死的選項會要你**按兩次**。死了：

- 死亡畫面寫出你怎麼死的、死法圖鑑進度、「怎麼避開」。
- **回到這一天早上**／**回到前一天早上**：每天早上自動存檔，保留兩份，存在瀏覽器裡（重新整理也還在）。回去後會多一張「似曾相識」的卡提醒你。
- 「重新開張」是次要選項。死法會記在**死法圖鑑**（跨局保存）。

### 成就與開張加成

31 個成就（死幾次、某種死法、走到某一層、收集舊物、店做多大、走到某個結局……）跨局保存，每個成就解鎖一個**開張加成**（共 27 種：多帶靈石、多一個月壽命、帶著某件遺物或裝備、開局就有阿宏或旺伯顧店、先修好某處店面……）。重新開張時挑選要帶的加成：一開始帶 1 個，每 4 個成就多 1 個，最多 4 個。

### 謎題簿

11 條會一路追下去的線（狐尾燈、十二年前的帳、末班車、停住的錶、霧裡的名字、阿妹、夜裡的客人、越走越深、點名簿、B2-17、分號），只寫你已經知道的，加一句下一步的方向。有新進展時分頁會標「有新的」。

### 第二輪改動（找上門、探索、遺物）
- **找上門的生意一天最多一件**；故事不受限。快過期又沒處理的生意，晚上由店裡的人照店規處理（店裡有眼力就照判斷，沒有就婉拒），日報「你不在的時候」會寫一行。
- **進去什麼都沒做就出來，不花時段。**「新」只算不會死的地方；只剩危險地方的，大廳顯示灰色一行「剩下的地方，最好別去」。
- **第一次去某個深處，會死的那幾處先不給走**，只留下徵兆句；下一次再來才出現。
- **站在邊上看一會兒**：不往裡走、不加負擔，花掉這個時段，換一條線索、喘一口氣（負擔－1），也會看出那一帶危險地方大概幾成會出事。
- **把最重的留下**：一趟一次，留下這趟撿到最值錢的一樣，負擔減一半；下次來可以撿回（負擔＋1）。回程危險不再寫百分比，改寫「會喘／不一定回得來／多半回不來」；帶著警示類遺物時，回程也要按兩次，並說大概幾成。
- **你記得**：死過、回到早上之後，那個地方會寫「你記得：死法」，並多一個「換個做法」：只看不碰、拿不到東西、負擔＋2，但不會那樣死。同一局同一種死法再死一次，死亡畫面只寫「它記得你。」
- **身上三格**：回程、保命、預感類遺物要帶在身上才有用，新撿到的有空位就自動帶上，在庫房可以換。日報有「身上」一欄，每件寫「今天出聲了／今天沒出聲」。
- **跨局記憶**：謎題簿記得上一次走到哪裡（灰字「上一次：」），新的一局第一天櫃檯會摺著上次的一句話。長生當鋪可以寄放一件遺物給下一次，下一局第三天送到。
- **用過之後**：五件用過就沒事的遺物（沒有字的茶籌、半杯冷茶、缺角的上行票、借來的半拍、遲到者的橡皮），用過一兩天後的早上會有人找上門：記得的人、帳本上多出來的印、夢裡還坐著的人。有些選擇會留一句話給下一局，第一天以「上一次留下來的」出現。
- **日報流水帳不重複**：用過的句子一局內不再出現，用完寧可留白。
- 死亡畫面與死法圖鑑依死法分類顯示圖示（探索、上升負擔、遺物、店裡）。

## 往外走（探索）

每個時段可以顧店、在聚落裡走動，或「往外走」。外面的地點分層，越深越怪、回程越累：

| 地點 | 層 | 備註 |
| --- | --- | --- |
| 舊國小・舊物室（`school`） | 聚落內 | 林老師：舊物可以賣、請她研究（解鎖物品隱藏句）、或捐出；她的黑板上有各種災變理論，沒有一個是官方答案 |
| 舊公路崩塌段（`ruin`） | 第一層 | 翻倒的公車、土地公廟、往上吹的風 |
| 舊隧道（`tunnel`） | 第二層 | 沒電也亮的燈、回聲、長進牆裡的車、盡頭的海水牆（吐納五層） |
| 寒潭水庫（`reservoir`） | 第二層 | 賣霧的阿伯、水底的村子、霧裡的路燈 |
| 西側斷崖・落海口（`cliff`） | 第三層 | 往下流的海、卡在半空的船、跟著指南針往下（吐納五層） |
| 北礦柵欄外（`north`） | 第四層 | 吐納五層才進得去；紀念碑、停在 2029 年的辦公室、會呼吸的通風口、霜的源頭 |
| 斷崖下的維修梯（`stair`） | 第五層 | 看過斷崖下的路燈才會出現；往下身體變輕、往上特別累；B2-17 實驗室、沒有終點站的站牌、23:59 的末班車（沒有票不要上車） |
| 燈街（`lampst`） | 第六層 | 從斷崖下往上看見、或搭過末班車才會出現；吐納六層；所有的鐘停在 23:58，窗裡有人在過晚上，許記五金 |
| 無底月台（`platform`） | 第七層 | 末班車的終點；站務室的日誌、往下看的軌道、不要等下一班車 |

- 一趟最多看兩處（帶登山杖三處）；走到標著「會累」（`strain`）的地方，這一趟就結束，回程多花一個時段。
- 每處會加負擔（`content/places_more.yaml` 的 `placeFx`），有 `danger` 的地方會用紅字寫出警告；`fx.death` 可帶 `chance`、`unless`（條件成立就不會死）與 `saved`（逃過一劫的文字）。
- 地點的危險度在店面上用 ●●○ 表示。
- 每個地點都有一處「翻翻看」（`repeat`），每天一次，從 `loot` 依 seed 抽一個結果——有時是遺物，有時只是一件怪事。
- 有些地方要身體適應到某一層（`need.level`／`minLevel`）；去得深會直接增加修行進度（`fx.xp`）。
- 遺物（`cat: relic`）大多不推動主線：有的只是怪、有的很溫柔、有的讓人不太好睡。每件都有林老師研究後才看得到的隱藏句。
- 早上的散事（`drift`）可以帶 `choices`，玩家在晨報上選；有不少散事只有在你看過某些地方、身上帶著某件遺物時才會發生。

| `content/shop.yaml` | 甩手掌櫃：方針、店的稱號、夥計、店面、日報文字、店裡事件（30 件）、探索裝備、成就、開張加成 |

| `content/relic_hooks.yaml` | 遺物接回事件：帶著某件遺物才會出現的地點（15 處）與散事（2 件，另有用過之後的後續 5 件）、加在舊事件上的遺物選項（6 個）、讓遺物可以救命的地點修補（4 處）；`reactions` 是「遺物不是鑰匙」：成對放著隔天出卡（4 對）、放久了自己引來一件事（4 件）、見過的遺物 15／30／45 件各一張卡 |

| `tools/batch_test.py` | 第一批外稿的定點測試（每個地點、死法、散事、夥計都跑一次） |
| `tools/smoke.py` | iPhone 尺寸冒煙測試，截圖到 `/workspace/shots/` |
| `tools/play.py` | 像真人一樣只點畫面按鈕的完整試玩：`python3 tools/play.py <cautious/greedy/explorer/story/reckless> <seed> [回溯次數]` |

## 寫內容的慣例

- 交易、晨報、消息單、偷聽、攤位、藥田加 `month: 2` 就只在第二個月出現；`month: all` 每個月都在。
- 台詞可以加 `f:` 指定表情（neutral smile laugh cold angry shock sad cry uneasy think sweat smug）。說謊的人在沒有修行門檻的台詞上不要用會洩題的表情；微表情放在 `tells` 裡。
- 人物外觀在 `npcs.yaml` 的 `look`。
- `meta.months.N` 是第 N 段有事的日子：`name`（畫面上的月份）、`gap`（跳過平淡日子時的卡）、`days`、`marketDay`、`noDues`、`lastDayTag`、`lastNight`。內容裡的 `month: N` 仍指這一段。
- 最終評等：`meta.goalLevel`（要到的層數）、`meta.grade.top`／`low`（被騙＋錯怪的上限／下等門檻）。
- 層數 1–9 顯示吐納，10–12 築基、13–15 金丹、16–18 元嬰（都是在地人對「身體適應程度」的稱呼）。
- 新增的 `need` 條件：`level`（吐納層數）、`done`（探索過的 spot id）。`fx.xp` 直接增加修行進度。
- 用語：店／管理處／派出所／寒潭會；不要用舖子、掌事、宗門、真君這類古風詞。不要寫出任何「官方真相」，尤其不要把災變寫死成 AI 造成的。
- 交易或事件的 `fx` 可用 `lifespan: 月數` 增減壽命。

## 線索規則（審核用）

- 非誠實交易：3～5 條線索，分佈在至少 3 種管道（話術、數字、物品文本、消息、第三方、身體反應、鑑定）。
- 單一線索不能直接定案；每個破綻都有一個無辜的解釋。
- 誠實交易也帶 1～2 條看似可疑、實則無辜的線索。
- 編出來的說法「太完整」；真話有生活感的缺口。

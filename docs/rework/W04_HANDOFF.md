### Q01：保留生命交易，還是改成一般債務？

| 方案 | 具體設定與影響 |
| --- | --- |
| A：保留生命交易（統籌建議） | 主角曾為家庭債務付出壽命代價，剩18個月的期限與300換回1個月功能保留。這是災後存在的特殊交易，具體機理、起源及可靠程度暫不定，尤其不連到AI或末日原因。交易機構與當票的日常用詞後續局部修，不能假裝是普通銀行；不新增每月醫療、晶片或新儀器。保留機制不代表認可舊古風句子。 |
| B：改為一般債務期限 | 18個月代表契約到期壓力，300成為延展／還款功能。需一起改開場、介面、月底、典主、當票及相關後果；壽命原本的意義不能只換文字。本案是另一次玩法及敘事決策，不能在本輪默默採用。 |

統籌建議A的理由：保留特殊世界與原有期限壓力，工程改動較小，也不必現在揭露生命交易原理。這只是建議，不替偉銓決定喜不喜歡此機制。

### Q02：地方職責分開，還是保留集中管理？

| 方案 | 具體權責與影響 |
| --- | --- |
| A：職責分開（統籌建議） | 派出所承接地方秩序與報案；聚落管理單位承接店家規費；礦區／資源組織處理供貨與配額；藥行處理專業採購及驗收。周正與陸各自角色須按既有線索再對照，不一口氣定全名、法律或行政層級。資源組織不因改名變成派出所，舊關係與利益差異逐案保留。普通規費80及既有高檔100／110不自動調整；高檔收取依據仍需敘事對照。 |
| B：資源勢力集中管理 | 同一地方勢力掌握資源、收費與執法；派出所只是其地方秩序窗口。能保留舊權力結構，但須讓居民的日常經驗與權責說得通，不能套用今天臺灣整套制度。 |

統籌建議A的理由：店家、供貨者與秩序窗口更有各自功能，符合前兩月的人物生活；沒有讓一名角色管理全部機關。方案A尚不是一份完整制度設定，周正／陸及高檔規費對照要隨實際移植審閱。

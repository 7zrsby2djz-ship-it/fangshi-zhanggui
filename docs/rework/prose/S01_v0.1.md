# S01｜先放著

版本：v0.1｜可審閱草稿，尚未核準｜M1D1，許記｜正文開始

許衡把最後一塊寒鐵放上秤，秤盤碰到木檯，喀了一聲。他伸手扶住，等秤桿不晃了，才在紙上補一筆。

「十斤喔？」

錢不語站在門口，手搭著門框。許衡沒抬頭，先把鐵放回布上。

「你隔那麼遠也看得到秤？」

「我看得到你那張臉。點貨的時候，比看人還認真。」錢不語跨進來，拖了張凳子坐下，「剛好，我來幫你清一清。」

許衡把秤砣挪回原位。「你要買？」

「北面又開一條礦脈，外面都在講。貨一多，這些就沒現在的價了。六塊一斤，十斤我全收，你省得慢慢賣。」

早上那張消息單也寫著北面的礦。許衡看過，上頭兩個字是「聽說」。他把單子翻回來，壓在秤旁。

「新開的在哪一段？」

「北面啊。你問我哪一段，我又沒下去挖。」錢不語探頭看那張紙，「聽雨樓都傳出來了，總不會只有我聽到吧？」

「誰先講的？」

「七娘那邊，你有空自己去問。我今天是來買鐵，不是來考試。」

錢不語拿起一塊，拇指擦過邊角，又把另外幾塊翻了一遍。許衡將布邊拉開，讓他看清楚，沒有接話。

「六塊半。」錢不語把鐵放下，「好啦，幫你加半塊。」

許衡看著秤旁那張紙。六十五塊收進來，今天的帳會好看很多。可是紙上沒寫誰去過那條新礦，也沒寫什麼時候能出貨。

「你不是說要跌？」

「要跌又不是現在不能用。我有客人，我得備貨。你想等高價，我也不能坐在這裡陪你等。」錢不語拍了拍膝蓋，「一句話，要不要？」

許衡把兩塊鐵疊回去，將布角收好。

「今天先不賣。」

錢不語伸出去的手停在布邊，隨即收回。「你要賣多少？」

「我還沒決定。」

「那我怎麼跟你談？」

「你價錢講清楚了，我也聽到了。等我問過再算。」許衡把那張消息單抽出來，「不是說你的消息不對。我只是還不知道它是哪來的。」

錢不語站起來，將凳子推回檯下，推到一半又拉正。

「好。鐵你留著，跌了別跑來說我沒提醒。」

「你也不用一直說在幫我。」

錢不語回頭，張了張嘴，最後笑出一聲。「許半兩，你這張嘴，真的很難做生意。」

「你下次還是會來。」

「那要看你的價。」

他出了門，許衡才把凳子往外拉一點，留給下一個人坐。布裡仍是十斤鐵。他沒在帳上添收入，只在消息單邊上寫了幾個字：北面的新礦，誰去看過？

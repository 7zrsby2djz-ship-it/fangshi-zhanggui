# S01 v0.3｜文風修正與狀態核對

版本：v0.3。偉銓表示 v0.2「差不多可以了」，並要求重量用公克、公斤；本次依此修正。v0.1 已因中國古風退件，先前自檢沒有充分檢查整體年代感。本次不沿用其文風判定。

## 本次修正

- qian 本幕稱「老錢」，hantie 暫稱「礦料」；穩定 ID 與原版數值不變，正式姓名、材料名稱仍屬工作候選。
- 重寫店內動作：鐵箱、磅秤、夾板、手推車、抹布與貨架服務點貨、議價和離店。這些是日常外觀，不宣告新工業產能。
- 對話圍繞誰先傳消息、買方等貨的成本與賣方猶豫；不用古腔稱呼、俠客式機鋒或深意綽號。
- 拒絕後再報七塊，是本幕議價草稿；不證明對方說謊，也不把買方真正訂單寫成已知。
- 結尾保留許衡對七十塊的捨不得，讓決定有生活代價，不以一句哲理替人物收場。

## 公制重量

本稿將原來十台斤按每台斤 600 公克改寫為六公斤。起價每公斤十塊，後續改報整箱六十五、七十；全部未成交。材料能力與總價不變。這是稿件呈現，舊引擎仍使用原數量／單位；W04 必須同步處理資料單位、單價、庫存與顯示，不可只改單位字樣。

## 主企劃八項退件標準

1. 主角沒有穿越、失憶或不懂在地生活；點貨、算價、查來源都是工作行為。
2. 沒有取得未發生的查證結果；傳單與老錢的轉述可能同源，不當雙重佐證。
3. 關鍵台詞有當下目的：賣方釐清價格依據，買方想趕快買到貨；不是替讀者說教。
4. 動作對應工作與壓力：翻料、捏抹布、加價後停手、接住椅背；不靠表情送答案。
5. 後半段仍是賣不賣這六公斤礦料，沒有新增支線或第二幕。
6. 沒有改變材料能力、取得方式或數量，特殊燈未出場。
7. 不提末日原因，也不由旁白證實礦場消息或買方訂單。
8. 空車、加價與買方說法都不足以獨立判定騙局；許衡只決定暫不賣。

另加整體文風檢查：使用當代繁體敘述與臺灣店家互動，不以舊名稱決定場景。v0.2 的臺灣口吻已獲偉銓大致認可，可沿用作後續文風基準；這不等於全部世界機制或正式遊戲版本已核准。

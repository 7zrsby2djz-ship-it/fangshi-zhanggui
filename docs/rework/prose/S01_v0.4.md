# S01｜這批先留著

版本：v0.4｜偉銓於2026-10-03通過，核准文風樣本｜M1D1，店內｜正文開始

許衡蹲在櫃台後面，把鐵礦石一塊塊裝回鐵箱。磅秤擺在旁邊，紙上記著六公斤。他才放好最後一塊，門口就有人喊。

「小許，這批你要放多久？」

是對面開店的老錢。他把手推車停在門外，進來時還順手扶了一下歪掉的門擋。

許衡站起來，拍掉膝蓋上的灰。「你要買就問價錢，問得好像我放在你家。」

老錢笑了，拉張椅子坐下。「我怕你放到不值錢啊。北邊又挖到一批，等那批運下來，你這些還賣得掉？」

「多少？」

「一公斤十塊。整箱我搬走，你也不用拆著賣。」

許衡沒蓋箱子。老錢彎腰翻了兩塊，挑起其中一塊，對著門外的光看。

「新的在哪裡挖到？」許衡問。

「北邊啊。」

「北邊很大。」

「你問這麼細，我又沒去挖。」老錢放下手裡那塊，揉了揉手指，「外面都在講，早上的報紙你沒看？」

早上他看過那份報紙，現在還壓在櫃台的夾板底下。那段寫的是「聽說」，後面沒寫誰去過，也沒寫什麼時候能出貨。

「所以你也是看那張？」

「有人跟我講。是不是同一個消息，我哪知道。」

「誰？」

老錢抬起頭。「你到底是要賣東西，還是要查我跟誰來往？」

許衡把夾板放回去，拿抹布擦手，沒接話。

「好啦，整箱六十五。」老錢往後靠，「現在就給你。你也不用再慢慢零賣，省多少事。」

六十五塊，這幾天買午餐就不用算半天了。許衡看了一眼箱子，手裡的抹布捏著，沒有往下放。

「你不是也怕跌？怎麼還要整箱？」

「我有客人在等啊。等它跌？人家早就跟別人買了。」老錢看著他，「你要等，我又不能跟著等。」

許衡把抹布掛回櫃台側面。

「我知道啊。可是我還沒問清楚，今天先不賣。」

老錢低頭看了箱子一會兒。「那七十塊呢？」

許衡原本要伸手拿箱蓋，又停住了。

「你先不要一直加。我真的還沒決定。」

「七十塊也沒決定？」

「就還沒想好啊。」

老錢把椅子往後推，站了起來。許衡伸手接住椅背，免得撞到後面的貨架。

「好啦。之後跌了不要怪我。」

「我自己留的，怪你幹嘛。」

老錢走到門口，抓住推車把手，又回頭問：「真的不賣喔？」

許衡搖頭。他嘖了一聲，拉著空車回對面。

店裡安靜下來。許衡蓋上箱子，把早上的報紙抽出來。在「聽說」旁邊，他寫下：最早是誰講的？

那七十塊還是讓他有點捨不得。他把紙夾好，拿掃把清掉剛才灑在地上的碎屑。

# S02｜桌子先還給我

版本：v0.1｜待審閱原型，未入遊戲／未測可玩｜M1D2，許記｜正文開始

老葛把空木箱放在門邊，兩手按住翹起的箱蓋。

「小許，你這裡有沒有空箱子？這個實在蓋不起來。」

許衡從櫃台後走出來。他剛才在看報紙，手指還夾在城東那一段：連下了三天雨，幾家鋪子的倉庫進了水。旁邊印著「坊間」，沒寫是哪幾家。

「只有裝鐵礦石那個，我還要用。你裝什麼？」

「乾藥草。都攤在吃飯桌上，小滿昨天端著碗站在旁邊，叫我先把桌子還她。」老葛鬆開一隻手，蓋子立刻彈起來，「總不能叫她蹲著吃。」

站在他旁邊的韓九接過箱蓋，免得老葛再壓。韓九幫人走山路送貨，提東西時習慣先掂一下重量。

「這麼大一個，裝滿你搬得動？」

「放家裡的，又不是要背上山。」老葛說，「你幫我拿個蓋子，已經嫌重了喔？」

「我是在想我自己的。」韓九把蓋子靠在腿邊，「上一趟回來，連飯都懶得煮。下一趟想跑近一點，當天回來就好，還扛這種箱子幹嘛。」

「那貨你隨便包一包？」

「也不行啊。送到人家那邊，拆開不能用，這趟就白跑了。」

老葛伸手摸箱口，又試著把蓋子的一角卡進去。許衡扶住另一側，木頭的邊緣歪了一截，對不上。

「先別壓了。你那批乾了沒？」

「還在晾。收早了悶壞，哪有人要。」老葛把手收回來，「不收，晚上又得清桌子。我一天到晚搬來搬去。」

韓九朝櫃台上的報紙抬了抬下巴。

「城東那幾家才麻煩，倉庫聽說進了水。」

「你去過？」許衡問。

「沒有。我也是看這個。」

老葛搖頭。「我更沒去。我的都在屋裡，是沒地方擺，不是淹到。」

許衡把報紙合起來。「這邊目前沒箱子能給你。這個蓋子先別硬塞，弄裂了更難用。」

「好啦，我回去再挪。」老葛彎腰抱起空箱，韓九把蓋子放到他手上。老葛沒接穩，兩人又停下來換了個拿法。

「你不是想早點回去煮飯？幫我扶一下啦。」

「這個扶完，還有沒有下一個？」韓九問。

「今天沒有了。」

等兩人走出門，許衡在紙上記下：老葛要收好家裡的乾貨；韓九想跑近、少扛一點。城東那段另記「報紙，坊間，還沒問到去過的人」。

他把便條夾在報紙裡，回去整理櫃台。店裡那箱鐵礦石還在原位，暫時也騰不出箱子。

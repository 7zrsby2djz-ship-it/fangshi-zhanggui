# S02｜桌子先還給我

版本：v0.2｜v0.1文風未通過，本版待偉銓審閱｜未入遊戲／未測可玩｜M1D2，許衡的店｜正文開始

老葛把空木箱放在門邊，兩隻手壓著翹起來的蓋子。

「小許，你這裡有沒有空箱子？這個怎麼蓋都蓋不起來。」

許衡從櫃台後面走出來。剛才看到一半的報紙還攤著，東邊那段寫著：連下了三天雨，幾家店的倉庫進了水。旁邊標的是「傳聞」，沒說是哪幾家。

「只有裝鐵礦石的那個，我還要用。你要裝什麼？」

「曬乾的藥材。現在全攤在吃飯桌上，小滿昨天端著碗，站在旁邊叫我先把桌子還她。」老葛放開一隻手，蓋子就彈了起來，「總不能叫她蹲著吃吧。」

旁邊的韓九接住蓋子，讓老葛不用一直壓著。他平常幫人走山路送貨，東西拿到手上，總會先試一下重量。

「這麼大箱，裝滿你搬得動？」

「我放家裡的，又不是要背上山。」老葛說，「才拿一個蓋子，你就嫌重了？」

「我是在想我自己。」韓九把蓋子靠在腿邊，「上次回來，連飯都懶得煮。下一趟想跑近一點，當天就回家，哪還想扛這種箱子。」

「那你要怎麼包？隨便綁一綁？」

「也不能這樣啊。人家一拆，東西壞了，這趟不就白跑。」

老葛摸了摸箱子的邊緣，想把蓋子的一角先卡進去。許衡幫他扶著另一邊，箱子邊緣歪了一截，蓋子還是對不上。

「先不要硬壓。你那些都乾了嗎？」

「還在晾。太早收起來會悶壞，到時候就不能賣了。」老葛鬆手，「可是放著，晚上吃飯又要清桌子。我整天都在搬這些。」

韓九看向櫃台上的報紙。

「東邊那幾家更麻煩，聽說倉庫進水了。」

「你有去過？」許衡問。

「沒有，我也是看這張。」

老葛搖頭。「我也沒去。我的都放屋裡，只是沒地方擺，沒有淹到。」

許衡把報紙合起來。「我這邊真的沒有空箱子可以給你。這個蓋子先不要硬塞，弄裂就更難用了。」

「好啦，我回去再喬一下位置。」老葛抱起箱子。韓九把蓋子交給他，老葛沒拿穩，兩個人又停下來，換了一個拿法。

「你不是想早點回家煮飯？先幫我扶一下。」

「扶完這個，還有沒有別的？」韓九問。

「今天沒有了。」

兩人走出去後，許衡拿紙記下老葛想把家裡晾著的東西收好，韓九想跑近一點、少背一點。雨的消息寫在另一邊：報紙上的傳聞，還沒問到去過的人。

他把紙放進報紙裡，回去整理櫃台。裝石料的箱子還在原來的位置，現在也空不出來。

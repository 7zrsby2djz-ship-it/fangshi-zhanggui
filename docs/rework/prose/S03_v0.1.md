# S03｜先替這四包想辦法

版本：v0.1｜待審閱原型，未入遊戲／未測可玩｜M1D3，市集｜正文開始

許衡到鐵師傅的攤前時，韓九正拎著一張厚布，翻來翻去。

「不是昨天嫌箱子重？」許衡問。

「所以來找這個啊。」韓九把布展開，「明天往城東送四包乾香菇，一包一公斤，送完就回來。外面多包一層，總比扛箱子好。」

鐵師傅把縫了一半的工具袋移開，讓他們有地方攤布。

「先量，蓋不住買了也沒用。」

布上塗了蠟，大約一公尺見方，旁邊配著兩段棉繩。許衡沿著折痕翻了一遍，再舉起來對光看，沒有看見破洞。

「你要走哪段？」他問韓九。

「溪邊那條。昨天離開你店裡以後，我先走到石壁，水還在滴，剩下的沒走。我可不想到了才發現香菇濕了。」

昨天報紙上的城東雨訊沒寫誰看過；這次韓九說的是自己走到哪裡。許衡把布放下。「能滴點水試嗎？」

鐵師傅推來杯子。「試這裡。別往繩子上倒。」

許衡逐張滴了點清水，水珠停在上頭。他數了十下，翻過來摸，背面還是乾的。

「泡水也行？」韓九問。

「不行。」鐵師傅把濺出的水擦掉，「這是包裹布。你要丟進溪裡，我不賣你。」

韓九把布對折，壓出包角。「沒有要丟。邊邊開著，水照樣會進吧？」

「對，得覆住。貨本來濕的，也別指望包了會乾。」

許衡拉近棉繩，試著繞過折好的布包。「一份多少？」

「六塊，連這兩條繩子。我這裡就四份。」

韓九摸了摸口袋，沒拿錢出來。「我還得回去取貨、重包。等一下又有人叫我幫忙搬東西，真的不用走了。」

許衡想起他昨天拿著那個箱蓋，老葛一直按也按不平。

「你明早把四包帶來。我先把這些整理好，幫你包。全部三十六，要不要？」

韓九蹲下來，把一張布四角交疊，確認大小。

「香菇我先檢查。明早開門後過去，別叫我再回市場買繩子喔。」

「繩子一起算了。」

鐵師傅沒催，把工具袋拿回去，繼續縫裂口。

二十四塊先出去，三十六還沒收到。許衡摸著口袋裡的錢，停了一下，才數給鐵師傅。

「四份都給我。」

鐵師傅收好錢，將布和繩子推過來。韓九先走，許衡擦掉水珠，把試過的布攤了一會兒，才一份份疊起來。

回店後，他把這四份放在櫃台後，另外夾張紙：韓九，明早四包。原本那箱鐵礦石沒有打開。他把二十四塊記進帳裡，將明早要用的棉繩各配好，免得韓九來了還等他找。

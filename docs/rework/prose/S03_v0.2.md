# S03｜先替這四包想辦法

版本：v0.2｜語感局部修訂，待偉銓審閱｜未入遊戲／未測可玩｜M1D3，市集｜正文開始

許衡走到鐵師傅的攤位前，看到韓九拿著一張厚布，翻過來又翻過去。

「你昨天不是嫌箱子太重？」

「所以才找這個啊。」韓九拉開布，「明天送四包乾香菇去東邊，一包一公斤，送完就回家。外面再包一層，總比背箱子輕吧。」

鐵師傅把縫到一半的工具袋拿開，空出地方讓他們放布。

「先量一下。太小包不起來，買了也沒用。」

那張布塗了蠟，長寬大概各一公尺，配兩條棉繩。許衡順著折痕翻開，再拿起來對著光看，沒看到破洞。

「你明天走哪裡？」他問韓九。

「溪邊那條。昨天從你店裡出來，我有走到石壁那邊，水還在滴。後面就沒走了。我不想送到才發現香菇濕掉。」

昨天報紙只說東邊有店家的倉庫進水，沒寫誰看過。韓九這次說了自己走到的位置。許衡把布放回桌上。

「可以滴一點水試試看嗎？」

鐵師傅把杯子推過來。「試這裡，不要倒在繩子上。」

許衡每張都滴了一點清水。水珠留在布上，他數到十，再翻過來摸，背面還是乾的。

「那泡水呢？」韓九問。

「不行。」鐵師傅擦掉桌上的水，「這是拿來包東西的。你要丟進溪裡，我就不賣你。」

「沒有要丟啦。」韓九對折，把角壓好，「邊邊沒包好，還是會進水吧？」

「對，要蓋住。東西本來就濕的，包了也不會乾。」

許衡拿過棉繩，繞著折好的布試長度。

「一份多少？」

「六塊，這兩條繩子也算。我只有四份。」

韓九摸了摸口袋，沒有拿錢。「我還要回去拿貨，重新包。等一下又有人找我搬東西，真的走不了了。」

許衡想到昨天那個一直蓋不起來的箱子。

「不然你明早帶四包來。我先把這些弄好，再幫你包。全部三十六，你要嗎？」

韓九蹲下來，把一張布的四個角折在一起，看包起來有多大。

「香菇我會先檢查。明天早上你開門以後，我再過去，不要又叫我去市場買繩子。」

「繩子也算進去了。」

鐵師傅拿回工具袋，繼續縫破掉的地方，沒有催他們。

二十四塊得先付，韓九的三十六還沒拿到。許衡摸著口袋，停了一下，才把錢數給鐵師傅。

「四份都給我。」

鐵師傅收下錢，把布跟繩子推過來。韓九先走了。許衡擦掉水珠，讓布攤著放了一會兒，再一份一份摺起來。

回店後，他把四份放在櫃台後面，留張紙寫韓九明早帶四包來。原來裝石料的箱子沒打開。他記下剛才付的二十四塊，把每張布要用的繩子配好，免得明天還要讓韓九等。

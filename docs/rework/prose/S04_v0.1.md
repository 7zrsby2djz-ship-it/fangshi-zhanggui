# S04｜等他把結拉緊

版本：v0.1｜待審閱原型，未入遊戲／未測可玩｜M1D4，許記｜正文開始

韓九一進門就把四包乾香菇放上櫃台，肩帶還掛在手肘上。

「三十六我帶了。你先包，錢等一下給。」

許衡把前一天配好的布繩拿出來，挪開夾板，讓貨有地方放。「每包都一公斤？」

「對，袋口有記。你看一下。」

許衡鬆開第一包的口，香菇的味道散出來。他翻看靠袋口的幾朵，摸到的傘面乾燥，沒有黏在一塊；再看另外三包，才將袋口收好。

「先放中間，角交過來。」

他把第一張布四角依序覆上，繩子繞過底部。韓九站在旁邊，手伸出來，又縮回去。

「你要幫忙就按這裡，別拉。」許衡說。

韓九壓住包角。「我怕到那邊解不開。」

「這頭留著。拉這條，不是拉整個結。」

韓九試了一次，繩結鬆開，最外面的角翻起來。他又自己綁回去，提到膝蓋高，另一手托住底下。

「這樣拿，邊會不會開？」

許衡把露出的一角塞回重疊處。「這裡別翹起來。你背的時候也看一下，不能光靠我現在綁好。」

「我知道啦。上次回來連飯都懶得煮，這次想少弄一點事。」

許衡包第二份時，韓九終於把肩帶放到椅子上，照剛才的方式按住包角。第三份他自己包，繩子繞反了，許衡伸手替他換過來。

「昨天要是自己買回去，今天就在家弄這個。」韓九把剩下兩段繩子遞過來，「我光找齊就要跑半天。」

「你人來了還催我。」

「不催一下，我怕你順便找我搬箱子。」

四份包好，許衡逐個扶著，讓韓九放進原來的背架。最下面那包卡在架角，韓九退回來重放，這次沒有硬推。

「如果路上水大起來，這個可不能拿去泡。」許衡說。

「那我就先停。沒有要扛著貨去試溪水。」

韓九把背架靠在門邊，從口袋數出三十六塊。許衡當著他的面點完，收進櫃台抽屜，才把寫著四份的紙劃掉。

「用完跟我講一下，哪裡不好綁。」

「後天早上會路過，再跟你講。今天回來我只想煮飯。」

「先把貨送到啦。」

韓九背起架子，手往後摸了一下底部那包的位置，走出門。

許衡把空出的地方擦乾淨，帳上記下收三十六。昨天花出去的二十四回來了，還多十二。他把兩筆寫在一起，旁邊記了韓九答應再來的日子。

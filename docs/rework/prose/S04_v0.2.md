# S04｜等他把繩子綁緊

版本：v0.2｜語感局部修訂，已由偉銓通過（U20261003-08）｜未入遊戲／未測可玩｜M1D4，許衡的店｜正文開始

韓九一進門，就把四包乾香菇放上櫃台，肩帶還掛在手肘上。

「三十六我帶了。你先包，等一下給你。」

許衡拿出昨天配好的布跟繩子，把夾板放到旁邊，讓他把貨放好。

「每包都是一公斤？」

「對，袋口那邊有寫。你看一下。」

許衡打開第一包，聞到香菇的味道。他翻了幾朵靠近袋子開口的，摸起來是乾的，也沒有黏在一起。其他三包也看過，才把袋口重新收好。

「先放中間，這個角拉過來。」

他把布的四個角一個接一個蓋上去，繩子從下面繞過。韓九在旁邊伸出手，又收了回去。

「要幫忙就壓這裡，不要拉。」許衡說。

韓九壓著布。「我是怕送到那邊解不開。」

「這頭留著，到時候拉這條。不要整個結一起拉。」

韓九試了一次，繩子鬆了，最外面的布角也掀起來。他自己綁回去，提到膝蓋那麼高，另一隻手托著底下。

「這樣拿，旁邊會不會開？」

許衡把露出來的角塞回兩層布中間。

「這裡不要翹起來。背上去也要看一下，不能我綁好了，你就都不管。」

「知道啦。上次回來連飯都懶得煮，這次不想再弄那麼多事。」

包第二份時，韓九總算把肩帶放到椅子上，照剛才那樣幫忙壓住布角。第三份他自己包，繩子繞錯方向，許衡伸手換過來。

「昨天要是自己買回去，今天還在家裡弄這個。」韓九遞過剩下兩條繩子，「光把東西找齊，我就要跑半天。」

「人都來了，你還一直催。」

「不催，我怕你順便叫我搬箱子。」

四份都包好，許衡一包一包扶著，讓韓九放進原來的背架。最下面那包卡在架子的角落，韓九拿出來重新放，沒有硬推進去。

「路上水要是變大，這個不能拿去泡。」許衡說。

「那就先停啊。我又不是要背著貨試溪水。」

韓九把背架靠在門邊，從口袋數出三十六塊。許衡當著他的面點過，收進櫃台抽屜，把寫四份的那張紙劃掉。

「用過再跟我說，哪裡不好綁。」

「後天早上會經過，再跟你講。今天回家我只想煮飯。」

「你先把貨送到啦。」

韓九背起架子，手往後摸了摸最下面那包，才走出門。

許衡擦乾淨櫃台，在帳上寫收了三十六。昨天付的二十四也寫在旁邊，算下來多十二塊。他順手記下韓九說會再來的日子。

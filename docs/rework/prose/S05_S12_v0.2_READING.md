# S05｜不是叫你幫忙

老葛這次沒帶木箱，提了一袋乾薄荷葉來。

「三百公克，十塊。這包賣掉，桌子總算能用了。」

許衡接過來，放到櫃台上。「其他的呢？」

「搬開了。小滿說她拿著碗走來走去，不知道的還以為她在幫我趕鳥。」

許衡拿盤子，先倒半袋出來。葉子掉下來，最後還有一小堆碎屑。老葛看到，伸手把幾片比較完整的撥到上面。

「搬來搬去才弄碎的，沒有壞掉。」

「我先看一下。」

許衡把完整的葉子攤開，碎的撥到另一邊，湊近聞了聞，還有薄荷味。他翻到的地方都是乾的，沒看到黏在一起或發霉。剩下半袋也倒出來，沒有只看上面幾片。

老葛把空袋折了兩下，在旁邊等。

許衡把盤子放上秤，扣掉盤子的重量，一共三百公克。分開量，比較完整的兩百，碎的一百。

「這邊七塊，碎的一塊，全部八塊。」

老葛的手停在袋子的開口。「碎一點就少兩塊？」

「你看這些。」許衡把裝碎葉的盤子推過去，「客人要整片的，我拿這個給他，他會要嗎？」

「拿去裝香包，又沒差。」

「那也要分開，不能當整片的買啊。」

老葛捏著空袋，沒有馬上回答。許衡把兩盤都放在他伸手拿得到的地方，還沒收進櫃台後面。

「不然碎的你留著，我只買這邊。」

「不用，拿回去又要找地方放。」老葛把袋子攤平，「我是來賣東西，不是叫你幫忙。不要因為小滿講那些，你就多給我。」

許衡看向他。「所以我才要倒出來看啊。」

老葛抬起頭，又看了一眼那盤碎葉。

「好啦，八塊。袋子我拿回去。」

許衡用店裡的紙袋，把完整的葉子跟碎葉分開裝，寫上重量，再數錢給他。老葛一塊一塊點完，把自己的空袋捲好，塞進口袋。

「今天回去可以坐著吃了。」

「不要又在桌上放別的東西。」

「你跟小滿講的一樣。」老葛拿起門邊的帽子，往頭上一戴就走了。

許衡把兩袋放上貨架，碎葉另外放，免得下次拿錯。帳上寫了八塊，也記下兩袋各有多重。他刷掉盤子裡剩下的葉屑。這批還沒人買，今天先放好。

# S06｜飯有煮，焦了一點

許衡還沒把門完全打開，韓九就在外面，從門縫喊他。

「不是說早上嗎？我來了。」

「又沒叫你站著等。」許衡把門擋放好，讓他進來。

韓九從袋子裡拿出一張包過貨的布，攤在櫃台上。塗蠟的地方有幾條折痕，最外面的角沾了泥。他翻起那個角給許衡看。

「石壁那邊還在滴水，這裡有滴到。送到以後，四包都當面拆開，香菇沒濕，人家都有收。」

許衡摸了摸布的背面，現在是乾的。

「送到的時候，裡面呢？」

「也是乾的。沒有把貨放到溪裡，也沒淋一路，就那一段要小心。」

韓九把布拉平，繩子從袋子裡拖出來，垂在櫃台邊。他捏著繩結，伸手往背後比了一下。

「可是這個綁在架子旁邊，我去摸布的角，手會磨到。下次繩頭留另一邊好了。」

許衡拿過繩子，換到另一邊綁。

「放這裡你拉得到嗎？」

韓九把架子放到面前試位置。「這樣比較好。以前自己隨便綁，都沒覺得哪裡不好用。這次一路都在摸，才發現。」

「以後裝多少東西，也要再看，不能每次都跟這四包一樣。」

「我知道，現在又沒叫你包下一趟。」韓九解開繩子，把布摺好放回自己的袋子，「只是順便跟你講。」

許衡把手收回來。「好，我記一下。回去有煮飯嗎？」

「有，焦了一點。」

「忙著拆貨？」

「忙著坐。想說坐一下就好，聞到味道才站起來。」

許衡笑了。「你不是想早點回家吃飯？」

「有早回家啊。焦的刮掉，還是吃了。」韓九拉好肩帶，「至少不用背那個大箱子。」

他走後，許衡在原來寫四份的紙旁邊加了兩行：四包收貨時是乾的，繩頭換邊。第一行註明是韓九說的，這次沒有錢要收。

到了月底，那兩袋薄荷還放在貨架上。許衡拿出錢，一塊一塊數到八十，交給來收規費的人。對方收下，他才在帳上寫已經繳了。

他把剩下的四十四塊再數一次。錢跟那六公斤原礦分開記，貨還放在箱子裡，他能拿出來付錢的就只有這些。

韓九還沒說下次要走多久。許衡把記了繩頭位置的紙夾好，放回櫃台。要是又帶貨來，至少不用重新問他要拉哪一條。

# S07｜架子還能用

阿岳走進店裡，手上拿著一個鋼扣。他在礦區搬貨，肩膀上還留著背架壓出來的印子。

「韓九說你會幫人想怎麼綁。這個幫我看一下。」

許衡把帳本放到旁邊，沒馬上接過來。

「你要修，還是換新的？」

「換四個。架子又沒壞，總不能為了這個，整副重新買吧。」

阿岳把鋼扣放到櫃台上。扣子是U形的，兩端有固定用的孔。一邊被繩子磨出一個凹口，他用手指摸過去，碰到翹起來的邊，馬上把手收回來。

「昨天把貨卸下來，布罩的繩子又斷在這裡。」

「這是固定布罩的？」

「對，沒有拿來吊貨。布罩一掀起來，石頭粉就掉進脖子後面。」阿岳拉了拉衣領，「邊走邊抖，回去還要清乾淨。」

許衡拿尺量扣子裡面，再比厚度。內寬三公分，厚三公釐，孔在哪裡也記下來。

「四個都要換？另外三個呢？」

「都磨到了，這個最嚴重，我先拆這個。」

阿岳攤開手，扣子只占手掌一小塊地方。

「新的邊緣要平一點，不要又把新繩子磨斷。」

「架子沒帶，我也不能現在就說裝得上。」許衡放下尺，「你問過鐵師傅嗎？」

「問過。市場入口旁邊那間，門上掛工具袋的，就是他平常工作的地方，不用等市集。他有做這種扣子，但有沒有現成的，要去問。」

許衡在記尺寸的旁邊寫下位置。

「那你怎麼不自己去？」

「買四個回來，差一點又要跑回去。」阿岳指著紙，「韓九說你會先問清楚。我沒有要多漂亮，裝得上，不要刮繩子就好。」

許衡摸了摸口袋。上個月繳完錢，只剩四十四塊，不能有客人來問，就先把東西買回來。

「我明天早上先去看。你晚一點帶空架子來，當面試，尺寸不合就不買。」

「好，我拿來之前先刷掉架子上的粉。」

阿岳伸手要拿扣子，許衡把有毛邊的那頭轉開，讓他拿另一邊。

「這個帶回去，我記好尺寸了。其他三個先不要丟。」

「我又還沒買到新的。」阿岳放進口袋。走到門口還摸了一下，確認有帶著。

許衡把紙貼在夾板上，寫明天帶架子來試。新扣子還沒拿到，錢也還沒收。他把尺放回櫃台下面，拿回剛才的帳本。

# S08｜先裝到架子上

許衡出門前，從鐵箱裡秤出兩公斤鐵礦石，另外裝好。走到市場入口旁邊，就看到門上掛著工具袋，鐵師傅在裡面。

「這兩公斤你要買嗎？」

鐵師傅翻了幾塊，再放到自己的秤上。

「這些可以，二十塊。」

許衡點頭。鐵師傅數錢給他，把石料搬到工作台下面，再接過記著阿岳要的尺寸那張紙。

「固定布罩的扣子？有，先看孔的位置。」

四個U形鋼扣放到桌上。許衡每個都量了內寬跟厚度，照紙上記的位置比孔，再拿棉繩貼著裡面，來回拉幾下，沒有被邊緣勾到。

「四個多少？」

「十六，都照這個尺寸做的。」

「好，我帶回去裝在架子上試。」

許衡付了十六塊，鐵師傅把扣子推給他。錢跟扣子各點一次，他把紙放回口袋，帶著四個回店。

下午，阿岳把刷乾淨的空背架帶來。放下時拿腳撐住，免得倒向貨架。

「舊的我先拆下來了，你看。」

四個舊扣放在旁邊，每個磨到的位置都不一樣。許衡把新扣一個一個對上架子原來的孔，用阿岳帶來的原本那些固定零件裝好，再讓他穿回布罩的繩子。

最後一個才裝上去，阿岳就拉緊布罩。

「等一下。」許衡按著架子，「這邊還沒鎖到底。」

阿岳鬆手，蹲下去重新轉緊。兩人換邊再看一次，他才把布罩拉開、收回，試了幾次。

「這次沒有勾到。」

「用一整天會不會磨到，現在還看不出來。用完再看這段繩子。」許衡指給他看，「四個加上我去量、回來試，一共二十四，可以嗎？」

阿岳沿著邊緣摸過，還沒拿錢。他先背起空架，伸手拉布罩，轉身差點碰到櫃台，又往門口退了兩步。

「可以。不用整副換，下午還能用。」

他放下架子，拿出二十四塊，當面交給許衡。

「等一下還有一趟要搬。明天早上會經過，再跟你說繩子有沒有磨毛。」

「好，這四個舊的帶回去，不要混在一起。」

阿岳把舊扣放進自己的袋子，背好架子走到門口。

許衡扶著門，讓寬寬的背架過去。阿岳側身走出來，布罩掃到門擋，沒有勾住。他在外面又拉了兩下繩子，才加快腳步。

許衡把門擋放回原位，等明天早上聽他怎麼說。

# S09｜她還要有力氣回家

阿岳在開門前來了一趟，拉出背架上原本的繩子。

「昨天搬完，這段沒有刮斷。布罩也沒一直掀起來。」

許衡看了他指的地方，把用過的情況記在尺寸旁邊。阿岳收回繩子，背著架子走了，沒有留下東西，這次也不用付錢。

阿蘅來的時候，櫃台上只剩那張紙。她放下兩小包乾糧跟捲好的衣服，衣服往櫃台邊滾，她先伸手按住。

「韓九那趟是你幫他包的？我也想問一下。」

「你要去哪裡？會過夜嗎？」

「草坡那邊，走熟的地方。當天回來，可能採不到多少；再往前，還要經過山裡那個凹下去的地方，就要住一晚。」

許衡沒先說價錢，指了指她帶的東西。

「這些是要過夜帶的？」

「本來想都帶著，沒採到就再往裡面走。」

阿蘅把衣服塞回袋子。袋口鼓起來，她一隻手壓著、一隻手拉繩子，拉兩次才關起來。

「上次回去，東西要晾，衣服也要洗。我坐著看那堆，連站起來收都懶。」

許衡扶好袋子。「那這次還想走那麼久？」

「要有東西賣啊。」她的手停在繩子上，「可是又放著不弄，採回來也沒用。」

許衡在紙背面畫兩欄。一邊寫當天回來，把乾糧分開，讓她看只放一包的位置；另一邊寫過夜，把衣服跟第二包放回去。

「當天回來，衣服可以留家裡。要過夜就別為了減輕重量，連保暖的也不帶。」

「選近的，沒採到也不能再往裡面走了。」阿蘅看著第一欄。

「對，要真的回頭。這個我沒辦法替你做。」

她拿起衣服，又放下，還沒選哪一邊。

「我以為你有一套配好的，買了就能出發。」

「沒有，我剛剛才知道你要怎麼走。」許衡把紙推過去，「今天我先不接這個。我可以幫你分東西，但不能先答應哪一套一定夠用。」

阿蘅把兩包乾糧收回去。

「那我再想一下。熟的地方我知道，先不要又走到什麼都得帶。」

「紙拿去，可以照著看。」

她把紙摺好，放在捲好的衣服外面。走到門邊，許衡又問：「回來有要賣的，先問價就好。不用為了這張紙，特別留給我。」

「我知道，哪裡價錢好，我就賣哪裡。」

她把乾糧往袋子底下推，衣服換個方向放，這次沒硬拉繩子。許衡把門邊的椅子移開，她側著肩膀走出去，手還扶著袋口。

# S10｜壺還有人要用

韓九蹲在修水壺的攤位前，腳邊擠著兩個保溫壺。他把一個放進袋子，另一個的提把就卡住了。

「不要硬壓。」許衡經過，停下來看，「提把壞了又要修。」

「內膽剛換好，這趟要送回去。以前這樣放，走起來一直撞。」韓九撐開袋口，「放箱子又太占地方。」

陶師傅從桌子底下拿出兩個木片做的框，裡面墊著乾布。

「放這個試試看，不要讓壺直接碰木頭。」

許衡拿起其中一個壺，翻過來看底下有多寬。底下的角落固定著一片舊金屬，字刻得很淺：「2029.12」，下面還有「換內膽」。

「這片也是這次弄的？」他問。

「不是，送來就有了。」韓九伸手托著提把，「外殼是舊的，裡面早就換過。人家還在用，小心不要把底下那片弄掉。」

許衡把壺扶正，避開底下那個角，把墊在裡面的布往旁邊調。陶師傅拿來兩片隔片，讓提把那邊多一點空間。

「兩個套子十八塊。」陶師傅說，「讓它們不要撞在一起，不是掉下去也摔不壞。」

韓九把另一個放進去，抬起來，又放回去。

「套子可以，可是袋子這樣綁，還是會歪。」

許衡解開袋口的繩子，把兩個分別固定，再一起放回原來的袋子。比較重的那個靠背架放，提把朝外，沒有碰到另一個壺。

「你背起來看看。」

韓九站起來，左右轉了兩次，伸手摸袋子裡面，沒有再聽到兩個撞在一起的聲音。

「這樣好，我就怕半路又要拆開。」

「兩個套子，加上我幫你配、放好，一共二十八。你要自己弄也可以。」許衡放開扶袋子的手，等他想。

韓九把肩帶往上拉。「你弄好吧，我等一下還要去拿別的。不要又讓我找不到繩頭。」

許衡數十八塊給陶師傅，買下兩個套子，把布仔細墊回剛才試的位置。陶師傅收回其他木框，說他平常就在市場入口另一邊修東西，門邊掛了兩個空框。

韓九付了二十八塊，再自己拉緊一次繩子。

「後天早上過來，跟你說人家收到了沒。」

「也問一下提把有沒有鬆。」

韓九點頭，提起袋子還扶著那個舊壺的提把。許衡看他從攤位旁邊的窄縫走出去，本來想問金屬片上的字是誰刻的，最後只把擋路的空框拿開，讓他先把壺送回去。

# S11｜拿不到就回來

阿蘅先從便當盒裡拿出一塊乾糧，咬了兩口，才拿出袋子裡的布角，攤在櫃台上。

她把盒蓋收在手邊，免得乾糧的碎屑掉到布上。

「這次不走裡面那段了。去熟的草坡，順便拿這個。」

布上黏著一層薄薄的硬殼，邊緣有淡藍色，細細的線像葉脈。許衡彎下來看，沒有伸手去摳。

「上次帶回來的？」

「對，旁邊有個淺淺的凹處，那裡有霧。我用布碰一下，就結了一層。剪這個角帶回來，路上碎掉一半。」阿蘅用指甲抵著布邊，沒有碰到殼，「站在乾的這邊，手伸過去就拿得到。我想改用夾子。」

「人不用下去？」

「不下去。拿不到就回來，再往裡面走，又跟上次一樣。」

許衡讓她把布角收回去。

「陶師傅有修容器，去問他有沒有夾子跟罐子。我沒碰過那個霧。」

阿蘅把剩下的乾糧放進自己的袋子，蓋好空的便當盒，收起來。

「看了不合用，就不要買。」

兩人走到市場入口另一邊，門邊掛的空木框跟昨天說的一樣。陶師傅正在換容器裡的內襯，看到他們進來，把工具放到旁邊，空出一塊地方。

他拿出一支長木夾子，跟一個開口比較大的玻璃罐。罐子外面有木框，上面用木塞蓋著。

「一套二十，只有這套。夾子四十公分，罐子二百五十毫升。」

阿蘅先夾自己的布角，捏太緊，布翻了一下。她馬上放鬆，重新夾住邊緣。

「很薄，不用整個夾住。」許衡扶著罐口，讓她把布角輕輕放進去，再拿出來。木框擋著，罐子不會在桌上滾，塞子也蓋得回去。

「碎了我不會幫你黏。」陶師傅看著那層殼。

「沒有要你黏。」阿蘅收好布角，把空罐子放進自己的袋子試。木夾子伸出袋口，她移到旁邊，免得碰到臉。

許衡幫她把固定的繩子繞過木框。

「這套加上我幫你挑、弄好，三十二。用法就跟剛才試的一樣。」

「可以，沒拿到也不往裡面找。」

許衡付二十給陶師傅，接過夾子跟罐子。阿蘅數三十二給他，才把東西拿回自己手上。

「明天早上來跟你說，今天先走短的。」

出門前，她又提了提袋子，把長夾子換到外側。許衡扶開門邊垂下來的工具套。這次她沒帶過夜的那捲衣服，走出去也不用壓著鼓起來的袋口。

# S12｜盒子也有人留過名字

韓九一早過來，拿出綁壺袋的繩子給許衡看。

「送到了，兩個都拆開給人家看過。提把沒鬆，外殼也沒撞壞。」

「走路的時候有歪嗎？」

「有停下來把繩子再綁緊一次。不然套子有用，壺還是會在袋子裡晃。」韓九收回繩子，「我先去拿別的，這次沒有要再請你配。」

許衡幫他開門。阿蘅來的時候，他還站在門邊，讓她先背著袋子進去。

她把玻璃罐放在櫃台上，裡面有一片大概兩公分的薄殼，透明的邊緣有淡藍色，上面有彎彎的細紋。她沒有倒出來，只把木塞鬆開一點給許衡看。

「從乾的那邊夾到的，沒有下去，就這一片。昨天回家還有力氣把東西收好。」

「路上有碎掉嗎？」

「這片沒碎，上次那個布角也還留著。」她壓回塞子，「先不賣，我還不知道能拿來做什麼。」

許衡點頭，把罐子推回她手邊。

阿蘅解下長木夾子的固定繩，打開空的便當盒，把繩子放進去。盒蓋裡面刻了幾排字，名字磨得很淡，有些只剩一半。下面一行還看得清楚：「2029/12/31」。

「這幾個是誰？」許衡指著名字問。

「不認識，家裡一直拿這個裝乾糧、放小工具。長輩說是以前工作那邊送別時，同事留的。」阿蘅用拇指擦掉蓋子邊的一點碎屑，「誰送誰，我沒問過。」

許衡記得前兩天看過的壺底。

「那個舊壺也是這一年，上面寫十二月換內膽，但沒寫幾號。」

阿蘅把盒蓋轉向自己，再看了一次。

「以前沒特別看這些，只管蓋不蓋得起來。」

她沒再拿布擦那些磨得很淡的字，把繩頭收進盒子邊，輕輕蓋上。木夾子另外綁在袋子外面，罐子放回原來的位置。許衡扶著袋口，等她一樣一樣放好。

「便當盒不要也拿去碰霧。」

「吃飯用的，沒有要拿去試。」阿蘅背起袋子，這次自己扶開門擋，走了出去。

月底來收規費時，許衡從抽屜數出八十塊，交給對方。對方當面點完收好，他才把剩下的錢推回抽屜。兩袋薄荷還在貨架上，都還沒賣出去。

許衡關好抽屜，把櫃台邊的尺拿開，空出一小塊地方放晚飯的碗。他把椅子往裡面拉，坐下來，手總算不用再忙著幫人扶袋子。

# S05｜不是叫你幫忙

版本：v0.1｜待審閱原型，未入遊戲／未測可玩｜M1D5，許記｜正文開始

老葛這次沒帶木箱，拎來一袋乾薄荷葉。

「三百公克，十塊。這包清掉，桌子總算能用了。」

許衡把袋子接到櫃台上。「其他的呢？」

「挪開了。小滿說，拿個碗走來走去，不知道的還以為她在幫我趕鳥。」

許衡拿盤子倒出一半，葉子落下來，底下跟著一小堆碎末。老葛看見了，伸手把幾片比較完整的撥到上面。

「搬來搬去弄碎的。不是壞掉。」

「我先看。」

許衡把整片的葉子攤開，再將碎葉撥到另一側。靠近聞，薄荷味還在；翻看的地方乾燥，沒看到黏成塊或發霉。他把剩下半袋也倒出來，沒有只挑上面那幾片。

老葛把空袋折了兩下，站在旁邊等。

盤子放上秤，扣掉盤重，總共三百公克。分開再量，較完整的兩百，碎的一百。

「整片的七塊，碎的一塊。整包八塊。」許衡說。

老葛的手停在袋口。「就碎一點，少兩塊？」

「你看這些。」許衡把碎葉那盤往前挪，「客人要整片，我拿這個給他，他會收？」

「拿去裝香包又沒差。」

「那也得分開。我不能當整片的收。」

老葛捏了捏空袋，沒立刻回話。許衡把兩盤都放在他伸手能碰到的地方，沒有先收進櫃台後面。

「你想留碎的也可以，我只收這邊。」

「不用。又拿回去，還是要找地方放。」老葛把袋子攤平，「我是來賣貨，不是叫你幫忙。你不要因為小滿那幾句，就多算給我。」

許衡看著他。「所以我才先倒出來看啊。」

老葛抬了下頭，往那盤碎葉瞄了一眼。

「好啦，八塊。袋子我要拿回去。」

許衡拿出店裡的紙袋，把整葉和碎葉分裝，各記重量，才數錢給他。老葛一塊一塊點完，將自己的空袋捲好，塞進口袋。

「今天回去可以坐著吃了。」

「桌子不要又擺別的上去。」

「你跟小滿講的一樣。」老葛抓起門邊的帽子，往頭上一扣，走了。

許衡把兩袋放上貨架，碎葉另外排開，免得之後拿錯。帳上寫了八塊，又補上兩百公克、一百公克。他把盤裡殘留的葉屑刷乾淨，還沒有人買走這批，今天先把它收好。

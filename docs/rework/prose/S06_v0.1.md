# S06｜飯有煮，焦了一點

版本：v0.1｜待審閱原型，未入遊戲／未測可玩｜M1D6，許記｜正文開始

許衡還沒把門完全推開，韓九就從門邊的空隙喊他。

「不是說早上嗎？我來了。」

「又沒叫你站著等。」許衡把門擋放好，讓他進來。

韓九從袋裡抽出一張包裹布，攤在櫃台上。蠟面留下幾道折痕，最外面的角沾著泥點。他把那個角翻起來，指給許衡看。

「石壁那邊還在滴水，這裡有滴到。送到以後，四包當面拆開，香菇沒濕，對方都收了。」

許衡摸了摸布背，現在是乾的。「內側當時呢？」

「也是乾的。沒有把貨放到溪裡，也沒淋一整路。就那段要顧一下。」

韓九把布往外拉平，繩子從袋口拖出來，落在櫃台邊。他捏起繩結，做了個往背後探的動作。

「但是這個綁在架子旁邊，摸包角會磨到手。下次留個頭在另一邊吧。」

許衡接過繩子，換到另一側試綁。「這頭你拉得到？」

韓九把架子放到身前比了一下。「這樣好一點。以前自己亂綁，也沒覺得哪裡不順；這次一趟一直摸，才知道。」

「以後裝多少，還得重看，不能每次照這四包。」

「我知道，現在又沒要你包下一趟。」韓九把結解開，將布疊回自己的袋子，「只是順便跟你講。」

許衡收回手。「好，記起來了。回來有煮飯嗎？」

「有。焦了一點。」

「忙著拆貨？」

「忙著坐。想說先坐一下，坐到聞到味道才起來。」

許衡忍不住笑。「你不是要早點回來吃飯？」

「有早點回來啊。焦的地方刮掉，還是吃了。」韓九把肩帶拉好，「至少沒扛那個大箱子。」

他出門後，許衡在原本那張四份的紙旁加上：四包收貨時乾；繩頭換邊。前一句註明韓九說的，紙上沒有多添一筆收入。

月底結帳時，那兩袋薄荷還在貨架上。許衡拿出錢，一塊一塊數到八十，交給來收規費的人，對方收下，他才在帳上劃記已付。

剩下四十四。他又數了一遍，和那六公斤鐵礦石分開記，沒有把還沒賣的貨當成口袋裡的錢。

韓九下趟要走多久，還沒說。許衡把改過繩頭的那張紙夾好，收進櫃台；如果又帶貨來，這次至少不用先問他結要拉哪條。

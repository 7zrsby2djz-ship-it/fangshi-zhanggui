# S06｜飯有煮，焦了一點

版本：v0.2｜語感局部修訂，待偉銓審閱｜未入遊戲／未測可玩｜M1D6，許衡的店｜正文開始

許衡還沒把門完全打開，韓九就在外面，從門縫喊他。

「不是說早上嗎？我來了。」

「又沒叫你站著等。」許衡把門擋放好，讓他進來。

韓九從袋子裡拿出一張包過貨的布，攤在櫃台上。塗蠟的地方有幾條折痕，最外面的角沾了泥。他翻起那個角給許衡看。

「石壁那邊還在滴水，這裡有滴到。送到以後，四包都當面拆開，香菇沒濕，人家都有收。」

許衡摸了摸布的背面，現在是乾的。

「送到的時候，裡面呢？」

「也是乾的。沒有把貨放到溪裡，也沒淋一路，就那一段要小心。」

韓九把布拉平，繩子從袋子裡拖出來，垂在櫃台邊。他捏著繩結，伸手往背後比了一下。

「可是這個綁在架子旁邊，我去摸布的角，手會磨到。下次繩頭留另一邊好了。」

許衡拿過繩子，換到另一邊綁。

「放這裡你拉得到嗎？」

韓九把架子放到面前試位置。「這樣比較好。以前自己隨便綁，都沒覺得哪裡不好用。這次一路都在摸，才發現。」

「以後裝多少東西，也要再看，不能每次都跟這四包一樣。」

「我知道，現在又沒叫你包下一趟。」韓九解開繩子，把布摺好放回自己的袋子，「只是順便跟你講。」

許衡把手收回來。「好，我記一下。回去有煮飯嗎？」

「有，焦了一點。」

「忙著拆貨？」

「忙著坐。想說坐一下就好，聞到味道才站起來。」

許衡笑了。「你不是想早點回家吃飯？」

「有早回家啊。焦的刮掉，還是吃了。」韓九拉好肩帶，「至少不用背那個大箱子。」

他走後，許衡在原來寫四份的紙旁邊加了兩行：四包收貨時是乾的，繩頭換邊。第一行註明是韓九說的，這次沒有錢要收。

到了月底，那兩袋薄荷還放在貨架上。許衡拿出錢，一塊一塊數到八十，交給來收規費的人。對方收下，他才在帳上寫已經繳了。

他把剩下的四十四塊再數一次。錢跟那六公斤原礦分開記，貨還放在箱子裡，他能拿出來付錢的就只有這些。

韓九還沒說下次要走多久。許衡把記了繩頭位置的紙夾好，放回櫃台。要是又帶貨來，至少不用重新問他要拉哪一條。

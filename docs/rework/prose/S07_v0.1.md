# S07｜架子還能用

版本：v0.1｜待審閱原型，未入遊戲／未測可玩｜M2D1，許記｜正文開始

阿岳進店時，手裡捏著一只鋼扣。他在礦區搬貨，肩膀上有道背架留下的壓痕。

「韓九說，你會幫人想怎麼綁。我這個你看一下。」

許衡挪開帳本，沒有直接伸手接。「要修，還是要買新的？」

「換四個。架子好好的，不能因為這個，整副都重買吧。」

阿岳把鋼扣放上櫃台。扣子彎成U形，兩端有固定孔，其中一邊被繩子磨出凹口。他用手指沿著凹口劃了一下，摸到翹起的邊，立刻收手。

「昨天下貨，罩布的繩子又斷在這裡。」

「固定罩布的？」

「對，不是吊貨的。罩布掀起來，碎石粉全往人後頸跑。」阿岳拉了拉衣領，「一邊走一邊抖，回去還得弄乾淨。」

許衡拿尺量內側，再比扣子厚度。內寬三公分，厚三公釐，孔的位置也記在紙上。

「你要整個架子換扣？另外三個呢？」

「都磨了。這個最嚴重，先拆來。」

阿岳將手掌攤開，鋼扣只占一小塊地方。「新的邊要平一點，別讓我又拿新繩子去磨。」

「架子沒帶，我現在不能說裝了就合。」許衡把尺放下，「有找過鐵師傅？」

「找過。市場入口旁那間，門上掛工具袋的，就是他平常做事的地方，不用等市集。他有做這種扣，現成的有沒有，得去問。」

許衡在尺寸旁加上工坊的位置。

「你自己怎麼不去？」

「去買四個再拿回來，萬一差一點，又要跑。」阿岳指著紙，「韓九說你會先弄清楚。我不是要買最漂亮的，能合、邊不要刮繩子就好。」

許衡摸了摸自己的口袋。上個月繳完費，手邊只剩四十四，這次也不能聽到有客就先買。

「我明早先去看。你晚一點帶空架來，當面試。沒有合的就不買，不硬湊。」

「好。拿來前，我先把上面的粉刷掉。」

阿岳伸手要抓鋼扣，許衡把有毛邊的那端轉開，讓他捏另一側。

「這個你拿回去，我尺寸記了。剩下三個先別丟。」

「我又不是買好了。」阿岳收進口袋，走到門口時還摸了一下，確定沒有漏掉。

許衡把紙貼在夾板上，旁邊寫：明天帶架來試。今天還沒拿到新扣，也沒收錢。他將尺放回櫃台下，把原本的帳本挪回來。

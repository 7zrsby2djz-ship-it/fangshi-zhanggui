# S08｜先裝到架子上

版本：v0.1｜待審閱原型，未入遊戲／未測可玩｜M2D2，工坊與許記｜正文開始

許衡出門前，從鐵箱裡秤出兩公斤鐵礦石，另外裝好。到市場入口旁，果然看見掛著工具袋的那扇門，鐵師傅就在裡面。

「這兩公斤你收不收？」

鐵師傅翻看幾塊，又放到自己的秤上。

「這些可以，二十塊。」

許衡點頭。鐵師傅數錢給他，把礦石移到工作台底下，才接過阿岳那張尺寸紙。

「罩布扣？有，先看孔。」

四只U形鋼扣放到桌上。許衡逐只量內寬與厚度，按紙上的位置比固定孔，再拿一段棉繩，貼著內側來回拉了幾下。繩子沒有被邊緣勾住。

「四只多少？」

「十六，四只都按這個尺寸做的。」

「我知道，要回去裝上架子試。」

許衡付了十六，鐵師傅把四只推給他。錢和鋼扣各點一次，他把尺寸紙塞回口袋，帶著四只回店。

午後，阿岳把刷乾淨的空背架帶進許記，放下時用腳撐了一下，免得倒向貨架。

「我把舊扣先拆了。這些你看。」

四只舊扣放在一旁，每只磨損的位置不一樣。許衡將新扣逐一對上原孔，用阿岳帶來的原固定件裝好，讓他穿回罩布的繩子。

最後一只剛上去，阿岳立刻拉緊罩布。

「等等。」許衡按住架子，「這邊還沒鎖到底。」

阿岳把手鬆開，蹲下來重新轉緊。兩人換邊再看一遍，阿岳才把罩布拉開又收回，試了幾次。

「這次沒有掛到。」

「整天會不會磨，現在看不出來。用完看繩子這一段。」許衡指了位置，「四只連我去量、回來試，二十四，可以嗎？」

阿岳沿邊摸過，沒有立刻掏錢。他背起空架，伸手去拉罩布，轉身時差點撞到櫃台，又往門口退兩步。

「可以。不用整副換掉，下午還能用。」

他放下架子，拿出二十四，當面交給許衡。

「等一下還有一趟要搬。明早會路過，再跟你說繩子有沒有毛。」

「好。這四只舊的你拿回去，別混在一起。」

阿岳把舊扣放進自己的袋子，背起修好的架子，走到門口。

許衡扶住門，讓那副寬架過去。阿岳側著身子往外挪，罩布掃了一下門擋，沒掛住。出去後，他又拉了兩下繩子，才加快腳步。

許衡把門擋擺回原處。等明早再看他怎麼說。

# S09｜她還要有力氣回家

版本：v0.1｜待審閱原型，未入遊戲／未測可玩｜M2D3，許記｜正文開始

阿岳開門前來了一趟，拉出背架上的原繩。

「昨天搬完，這一段沒被刮斷。罩布也沒一直掀起來。」

許衡看了他指的地方，將用後結果記在尺寸紙旁。阿岳收回繩子，背架也一起帶走；沒留下東西，這次也沒有錢要結。

阿蘅來時，櫃台上只剩那張紙。她將兩小包乾糧和一卷衣物放上去，先把滾向邊緣的衣卷按住。

「韓九那趟，你有幫他包？我也想問。」

「你要去哪、住不住？」

「草坡那邊，走熟的。當天回來，可能採不多；再過一個山坳，得留一晚。」

許衡沒有先開價，指了指她帶來的東西。「這些是過夜的？」

「原本想說都帶著。沒有採到，再往裡走。」

阿蘅提起衣卷，塞回袋裡。袋口鼓著，她一手壓，一手拉繩，拉了兩次才關上。

「上次回來，貨還得晾，衣服也得洗。我坐著看那堆東西，連起來收都懶。」

許衡把袋子扶正。「那這次還想走一樣長？」

「要有東西賣啊。」她說，手停在繩頭上，「可是再這樣放著，採到了也沒用。」

許衡在紙背畫兩欄。一邊寫當日回，把兩包乾糧分開，讓她看只帶一包的位置；另一邊寫過夜，把衣卷和另一包一起放回去。

「當天回來，這卷可以留家裡。過夜就別為了少一點重，把保暖的也省掉。」

「近的沒有，就不能再往裡加了。」阿蘅看著第一欄說。

「對，得真的轉回來。這個我不能替你做到。」

她把衣卷拿起，又放下，沒有先選。

「我本來以為你有一套配好的，拿了就能走。」

「還沒。你那趟怎麼走，我剛剛才知道。」許衡把紙推近，「今天這個我先不接。我能幫你分，但不能先答應哪套一定夠。」

阿蘅將兩小包收回袋子。「那我自己再想一下。熟的地方我知道，先不要又走到什麼都得帶。」

「這張你拿去，比著看。」

她接了紙，摺好放進衣卷外側。走到門邊，許衡又問：「回來如果有要賣的，先問價就好，不用為了今天這張紙留給我。」

「我知道。哪裡價錢好，我就賣哪裡。」

阿蘅把乾糧往袋底推，衣卷換了個方向，這次沒再硬拉繩子。許衡替她讓開門邊的椅子，她側著肩膀走出去，手仍扶著袋口。

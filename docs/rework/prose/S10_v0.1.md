# S10｜壺還有人要用

版本：v0.1｜待審閱原型，未入遊戲／未測可玩｜M2D4，市集｜正文開始

韓九在修器皿的攤前蹲著，兩只保溫壺擠在腳邊。他把一只壺往袋裡放，另一只的提柄立刻卡住。

「別硬壓。」許衡經過時停下來，「柄壞了又得修。」

「內膽才換好，這趟還要送回去。之前這樣放，走起來一直撞。」韓九把袋口撐開，「箱子又占地方。」

陶師傅從桌底抽出兩只木片做的外框，內側墊著乾布。

「用這個試。壺不要直接靠木頭。」

許衡接過其中一只壺，翻底看寬度。底角固定著一片舊金屬，字刻得很淺：「2029.12」，下面是「換內膽」。

「這片也是這次弄的？」他問。

「不是。送來就有了。」韓九伸手托住提柄，「殼是舊的，裡面早就換過。人家還在用，別把底弄掉。」

許衡將壺扶回正面，避開底角，把內襯往旁邊調。陶師傅拿來兩片隔片，讓提柄那側多留一點空間。

「兩個套十八。」陶師傅說，「只隔撞，不是摔不壞。」

韓九將另一只放進去，抬了一下，又放下。

「套可以，袋子這樣綁，還是會歪。」

許衡解開袋口的繩，把兩只各自固定，再一起放回原袋。較重的靠近韓九背架，提柄轉向外側，沒和另一只壺相碰。

「你背起來看看。」

韓九站起來，左右轉了兩次，伸手摸袋裡的位置。原本碰撞的聲音沒有再出來。

「這樣好。就怕走到一半又要拆開。」

「兩個套連我幫你配、弄好，二十八。你自己弄也可以。」許衡鬆開扶袋的手，讓他先想。

韓九把肩帶往上提。「你弄好，我等一下還得去取別的。不要讓我回來又找不到繩頭。」

許衡數十八給陶師傅，將兩個套拿下，仔細墊回剛才試的位置。陶師傅把剩下木框收回桌底，告訴他平日修東西就在市場入口另一側，門邊掛著兩只空框。

韓九付了二十八，自己再拉緊一次固定繩。

「後天早上來講，人家收到了沒有。」他說。

「也問一下柄有沒有鬆。」

韓九點頭，提起袋子時還扶著那只舊壺的柄。許衡看他挪過攤邊的窄縫，原本想問那片字是誰刻的，最後只伸手把擋路的空框移開。那只壺得先好好送回去。

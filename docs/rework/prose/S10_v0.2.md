# S10｜壺還有人要用

版本：v0.2｜語感局部修訂，待偉銓審閱｜未入遊戲／未測可玩｜M2D4，市集｜正文開始

韓九蹲在修水壺的攤位前，腳邊擠著兩個保溫壺。他把一個放進袋子，另一個的提把就卡住了。

「不要硬壓。」許衡經過，停下來看，「提把壞了又要修。」

「內膽剛換好，這趟要送回去。以前這樣放，走起來一直撞。」韓九撐開袋口，「放箱子又太占地方。」

陶師傅從桌子底下拿出兩個木片做的框，裡面墊著乾布。

「放這個試試看，不要讓壺直接碰木頭。」

許衡拿起其中一個壺，翻過來看底下有多寬。底下的角落固定著一片舊金屬，字刻得很淺：「2029.12」，下面還有「換內膽」。

「這片也是這次弄的？」他問。

「不是，送來就有了。」韓九伸手托著提把，「外殼是舊的，裡面早就換過。人家還在用，小心不要把底下那片弄掉。」

許衡把壺扶正，避開底下那個角，把墊在裡面的布往旁邊調。陶師傅拿來兩片隔片，讓提把那邊多一點空間。

「兩個套子十八塊。」陶師傅說，「讓它們不要撞在一起，不是掉下去也摔不壞。」

韓九把另一個放進去，抬起來，又放回去。

「套子可以，可是袋子這樣綁，還是會歪。」

許衡解開袋口的繩子，把兩個分別固定，再一起放回原來的袋子。比較重的那個靠背架放，提把朝外，沒有碰到另一個壺。

「你背起來看看。」

韓九站起來，左右轉了兩次，伸手摸袋子裡面，沒有再聽到兩個撞在一起的聲音。

「這樣好，我就怕半路又要拆開。」

「兩個套子，加上我幫你配、放好，一共二十八。你要自己弄也可以。」許衡放開扶袋子的手，等他想。

韓九把肩帶往上拉。「你弄好吧，我等一下還要去拿別的。不要又讓我找不到繩頭。」

許衡數十八塊給陶師傅，買下兩個套子，把布仔細墊回剛才試的位置。陶師傅收回其他木框，說他平常就在市場入口另一邊修東西，門邊掛了兩個空框。

韓九付了二十八塊，再自己拉緊一次繩子。

「後天早上過來，跟你說人家收到了沒。」

「也問一下提把有沒有鬆。」

韓九點頭，提起袋子還扶著那個舊壺的提把。許衡看他從攤位旁邊的窄縫走出去，本來想問金屬片上的字是誰刻的，最後只把擋路的空框拿開，讓他先把壺送回去。

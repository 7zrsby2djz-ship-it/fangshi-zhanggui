# S11｜只拿邊上的

版本：v0.1｜待審閱原型，未入遊戲／未測可玩｜M2D5，許記與供應點｜正文開始

阿蘅先從飯盒拿出一塊乾糧，咬了兩口，才把袋裡的布角展在櫃台上。

她把盒蓋收在手邊，免得乾糧屑掉到布角上。

「這次不過山坳。去熟的草坡，順便拿這個。」

布角黏著一小層硬殼，邊緣透出淡藍，細線像葉脈。許衡彎腰看，沒有先用手摳。

「上次帶回來的？」

「對。旁邊淺凹有霧，我拿布碰了一下，就結一層。剪了這角回來，路上碎掉一半。」阿蘅用指甲抵住布邊，沒有碰硬殼，「乾的這邊伸手夠得到，我想換夾子拿。」

「人不下去？」

「不下。拿不起來就回來。再往裡走，又是上次那樣。」

許衡把布角讓她收回。「陶師傅修容器，去問有沒有夾子和罐子。我沒碰過那個霧。」

阿蘅把剩下乾糧放進自己的袋子，空飯盒蓋好收起。「看完不合用，就別買。」

兩人到市場入口另一側，門邊掛的空木框和昨天說的一樣。陶師傅正在換容器的內襯，見他們進來，將工具挪出一塊空位。

他拿出一支長木夾、一只廣口玻璃罐，罐外有木框，口用木塞關。

「一套二十，就這套。夾子四十公分，罐子二百五十毫升。」

阿蘅先夾自己的布角。手收太緊，布翻了一下，她立刻鬆開，重夾邊緣。

「很薄，不用整個捏住。」許衡扶著罐口，讓她把布角輕放到裡面，再拿回來。木框不讓罐子在桌上亂滾，塞子也能蓋回。

「碎了，我不會替你黏。」陶師傅看著那層殼說。

「沒有要你黏。」阿蘅將布角收好，試著把空罐放進自己的袋子。木夾突出袋口，她往旁邊挪，免得碰到臉。

許衡幫她將固定繩繞過木框。「這套連我幫你挑、調好，三十二。只照剛才試的用法。」

「可以。沒拿到也不往裡找。」

許衡付二十給陶師傅，接下器具；阿蘅數三十二給他，才把罐子和夾子拿回自己手上。

「明早來跟你說。今天先走短的。」

她出門前又提了提袋子，將長木夾換到外側。許衡替她扶開垂在門邊的工具套，這次阿蘅沒有帶那卷過夜衣物，過門時也不用壓著鼓起來的袋口。

# S11｜拿不到就回來

版本：v0.2｜語感局部修訂，已由偉銓通過（U20261003-11）｜未入遊戲／未測可玩｜M2D5，許衡的店、陶師傅工作的地方｜正文開始

阿蘅先從便當盒裡拿出一塊乾糧，咬了兩口，才拿出袋子裡的布角，攤在櫃台上。

她把盒蓋收在手邊，免得乾糧的碎屑掉到布上。

「這次不走裡面那段了。去熟的草坡，順便拿這個。」

布上黏著一層薄薄的硬殼，邊緣有淡藍色，細細的線像葉脈。許衡彎下來看，沒有伸手去摳。

「上次帶回來的？」

「對，旁邊有個淺淺的凹處，那裡有霧。我用布碰一下，就結了一層。剪這個角帶回來，路上碎掉一半。」阿蘅用指甲抵著布邊，沒有碰到殼，「站在乾的這邊，手伸過去就拿得到。我想改用夾子。」

「人不用下去？」

「不下去。拿不到就回來，再往裡面走，又跟上次一樣。」

許衡讓她把布角收回去。

「陶師傅有修容器，去問他有沒有夾子跟罐子。我沒碰過那個霧。」

阿蘅把剩下的乾糧放進自己的袋子，蓋好空的便當盒，收起來。

「看了不合用，就不要買。」

兩人走到市場入口另一邊，門邊掛的空木框跟昨天說的一樣。陶師傅正在換容器裡的內襯，看到他們進來，把工具放到旁邊，空出一塊地方。

他拿出一支長木夾子，跟一個開口比較大的玻璃罐。罐子外面有木框，上面用木塞蓋著。

「一套二十，只有這套。夾子四十公分，罐子二百五十毫升。」

阿蘅先夾自己的布角，捏太緊，布翻了一下。她馬上放鬆，重新夾住邊緣。

「很薄，不用整個夾住。」許衡扶著罐口，讓她把布角輕輕放進去，再拿出來。木框擋著，罐子不會在桌上滾，塞子也蓋得回去。

「碎了我不會幫你黏。」陶師傅看著那層殼。

「沒有要你黏。」阿蘅收好布角，把空罐子放進自己的袋子試。木夾子伸出袋口，她移到旁邊，免得碰到臉。

許衡幫她把固定的繩子繞過木框。

「這套加上我幫你挑、弄好，三十二。用法就跟剛才試的一樣。」

「可以，沒拿到也不往裡面找。」

許衡付二十給陶師傅，接過夾子跟罐子。阿蘅數三十二給他，才把東西拿回自己手上。

「明天早上來跟你說，今天先走短的。」

出門前，她又提了提袋子，把長夾子換到外側。許衡扶開門邊垂下來的工具套。這次她沒帶過夜的那捲衣服，走出去也不用壓著鼓起來的袋口。

# S12｜盒子也有人留過名字

版本：v0.1｜待審閱原型，未入遊戲／未測可玩｜M2D6，許記｜正文開始

韓九一早來，把壺袋的固定繩拿給許衡看。

「送到了。兩只都拆給人家看過，柄沒鬆，殼也沒撞壞。」

「走起來有歪嗎？」

「有停下來緊一次繩。不然這個套用得上，壺還是會在袋裡晃。」韓九把繩收回袋子，「我先去取別的。這回沒有要你再配。」

許衡替他推開門。等阿蘅來，他還站在門邊，先讓她背著袋子進去。

阿蘅把玻璃罐放到櫃台上，裡面有一片大約兩公分的薄殼，透明的邊透出淡藍，細紋蜿蜒著。她沒有倒出來，只將木塞鬆開一點，讓許衡看。

「從乾的那邊夾到，沒下去。就這一片。昨天回來還有力氣把東西收好。」

「路上有碎嗎？」

「這片沒碎。上次那個布角還留著。」她把塞子壓回去，「先不賣，我還不知道拿它做什麼。」

許衡點頭，將罐子推回她手邊。

阿蘅解下長木夾上的固定繩，打開空飯盒，把繩子放進去。盒蓋內側有幾排刻字，名字磨得淡，有些只剩半邊，下面一行還看得清：「2029/12/31」。

「這些是誰？」許衡指了指那排名字。

「不認識。家裡一直拿這個裝乾糧、放小工具。長輩說以前工作送別，同事留的。」阿蘅用拇指擦掉蓋邊一點屑，「誰送誰，我沒問過。」

許衡記得前兩天翻過的壺底。「那只舊壺也是這一年，寫十二月換內膽。沒有這個日。」

阿蘅將盒蓋朝自己轉過去，又看了一次。

「這些我以前都沒特別看。只管能不能蓋好。」

她沒有再拿布去擦那些殘字，把繩頭收進盒邊，輕輕合上。木夾另綁在袋外，罐子放回原位；許衡扶著袋口，等她把這幾樣各自收好。

「飯盒不要也拿去碰霧。」他說。

「那是吃飯的，沒打算拿它去試。」阿蘅背起袋子，這次自己扶開門擋，走了出去。

月底來收規費時，許衡從抽屜數出八十，交到對方手上。對方當面點完收好，他才把剩下的錢推回去。那兩袋薄荷還在貨架上，沒有人替它們付過錢。

許衡合上抽屜，把櫃台邊的尺移開，騰出一小塊地方放晚飯的碗。椅子往裡拉了拉，這次坐下，不用再扶誰的包角。
